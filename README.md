**AI Civic Intelligence Portal** &nbsp;·&nbsp; `🏆 NATIONAL FINALIST — India Innovates 2026` &nbsp;·&nbsp; ![status](https://img.shields.io/badge/STATUS-DEPLOYED-0A0F1E?style=flat-square&color=A78BFA)
